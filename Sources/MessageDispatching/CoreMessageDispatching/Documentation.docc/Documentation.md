# SoftwareEtudes Messaging Framework

Welcome to the SoftwareEtudes Messaging Framework — a lightweight, flexible library for defining, dispatching, interpreting, and handling messages across your Swift applications.

- **Configurable dispatch pipeline** with pluggable filters and formatters  
- **Environment-driven template loading** for localised, coded or keyed messages  
- **Fine-grained argument sensitivity** (masking or dropping secret/private data)  
- **Extensible interpreter** to clean, mask, format, or log messages
